# SECURED WALLET — Demo

A simple red-and-white responsive wallet website built with HTML, CSS, and vanilla JavaScript.

## Run locally
Open `index.html` in a browser.

## Deploy to Netlify
1. Upload these files to a GitHub repository.
2. In Netlify, select **Add new project → Import an existing project**.
3. Connect GitHub and select the repository.
4. Leave the build command empty and set publish directory to `.`.
5. Deploy.
